# संघीय इको-विजन नर्मदा फाउंडेशन (Sanghiya Eco-Vision Narmada Foundation)
### आधिकारिक वेब पोर्टल • रखरखाव, विस्तार एवं वास्तुकला मार्गदर्शिका (Architecture & Developer Guide)

---

## 1. प्रोजेक्ट का उद्देश्य (Project Purpose & Overview)

यह वेब पोर्टल **संघीय इको-विजन नर्मदा फाउंडेशन** का आधिकारिक डिजिटल मंच है। इसका मुख्य उद्देश्य:
1. **माँ नर्मदा नदी का संरक्षण:** जल शुचिता, घाट स्वच्छता और प्लास्टिक प्रदूषण नियंत्रण।
2. **स्वयंसेवक सहभागिता:** नर्मदा तटवर्ती नागरिकों व युवाओं को संगठित कर ऑनलाइन सदस्यता पंजीकरण (`SEVNF-VOL-XXXXXX`)।
3. **सत्यापित डिजिटल सदस्यता प्रमाणपत्र:** अधिकृत सत्यापन के बाद वेबसाइट से सीधे उच्च-गुणवत्ता (High-Resolution) A4 लैंडस्केप PDF डाउनलोड (जिसमें असली गोल लोगो और लाइव QR कोड शामिल है)।
4. **सार्वजनिक QR सत्यापन पोर्टल:** किसी भी जारी प्रमाणपत्र की सत्यता की पुष्टि (व्यक्तिगत डेटा को सुरक्षित रखते हुए)।
5. **प्रशासनिक नियंत्रण (Admin Dashboard):** आवेदनों की समीक्षा, स्थिति परिवर्तन, CSV एक्सपोर्ट, नए जिले/तहसील/गाँव जोड़ना तथा सुरक्षित JSON डेटा बैकअप।
6. **शून्य बजट (Zero Budget):** किसी भी भुगतान वाली सेवा (Paid Service) के बिना, शत-प्रतिशत निःशुल्क तकनीकों पर निर्मित।

## 2. वेबसाइट चलाने का तरीका (How to Run Locally)

यह प्रोजेक्ट **React 19 + TypeScript + Vite + Tailwind CSS** पर आधारित है।

```bash
# 1. निर्भरताएँ (Dependencies) इंस्टॉल करें:
npm install

# 2. डेवलपमेंट सर्वर शुरू करें:
npm run dev

# 3. प्रोडक्शन बिल्ड तैयार करें:
npm run build

# 4. टाइपस्क्रिप्ट और कोड जाँच (Lint):
npm run lint
```

डेवलपमेंट सर्वर डिफ़ॉल्ट रूप से `http://localhost:3000` पर चलता है।

## 4. फाउंडेशन की जानकारी बदलने का तरीका (Changing Foundation Info)

फाउंडेशन की कोई भी सामान्य जानकारी बदलने के लिए **केवल एक फाइल** बदलें:
📂 `src/config/siteConfig.ts`

यहाँ आप सीधे बदल सकते हैं:
- `hindiName`: फाउंडेशन का हिंदी नाम।
- `englishName`: अंग्रेजी नाम।
- `tagline`: मुख्य ध्येय वाक्य ("माँ नर्मदा का संरक्षण, हमारा संकल्प")।
- `contact.phone`: फोन व हेल्पलाइन नंबर।
- `contact.email`: आधिकारिक ईमेल।
- `contact.address`: कार्यालयीन पता।
- `social`: व्हाट्सएप, फेसबुक, यूट्यूब, इंस्टाग्राम लिंक्स।

## 5. लोगो बदलने का तरीका (Changing the Official Logo)

1. अपनी नई लोगो इमेज को वर्गाकार/गोलाकार (Square/Circular) रखें।
2. इमेज को `public/logo.png` नाम से सेव करके `public/` फोल्डर में रखें।
3. यदि वेक्टर फॉर्मेट है, तो उसे `public/logo.svg` में रखें।
4. `src/config/siteConfig.ts` में `SITE_CONFIG.logo.primaryPath` को सत्यापित करें।
5. वेबसाइट के सभी स्थान (`CustomEmblem`, `CertificateView`, `Navbar`, आदि) स्वतः नया लोगो दिखाने लगेंगे।

## 6. रंग और थीम बदलने का तरीका (Changing Colors & Theme)

वेबसाइट के आधिकारिक 4 रंग केंद्रीय रूप से दो स्थानों पर परिभाषित हैं:
1. **CSS Variables:** 📂 `src/index.css`

   - `--theme-narmada-blue`: नर्मदा नीला (`#1c3f60`)
   - `--theme-gold`: हल्का सुनहरा (`#f59e0b`)
   - `--theme-white`: श्वेत (`#ffffff`)

इनमें बदलाव करने पर पूरी वेबसाइट की थीम सुसंगत रूप से अपडेट हो जाती है।

## 7. नया पेज जोड़ने का तरीका (How to Add a New Page)

भविष्य में नया पेज जोड़ने के सरल 4 चरण:
1. **टाइप जोड़ें:** `src/types.ts` में `PageId` यूनियन में नया नाम जोड़ें (उदा. `'events'`)।
2. **पेज कंपोनेंट बनाएँ:** `src/pages/` में नया कंपोनेंट बनाएँ (उदा. `EventsPage.tsx`)।
3. **नेविगेशन जोड़ें:** `src/components/Navbar.tsx` के `navLinks` ऐरे में नया लिंक और आइकन जोड़ें।
4. **App.tsx में रेंडर करें:** `src/App.tsx` में रूटिंग ब्लॉक और डॉक्यूमेंट टाइटल अपडेट करें:
   ```tsx
   {currentPage === 'events' && <EventsPage />}
   ```

## 8. डेटाबेस व बैकअप प्रबंधन (Database & Backup Protocol)

### वर्तमान स्टोरेज संरचना
- वेबसाइट शून्य बजट पर चलती है, इसलिए यह सुरक्षित **ब्राउज़र लोकल स्टोरेज (`localStorage`)** का उपयोग करती है।
- स्टोरेज कीज:
  - `sanghiya_narmada_volunteers_v2` (वॉलंटियर्स रिकॉर्ड्स)
  - `sanghiya_narmada_locations_v2` (स्थान व गाँव सूची)
  - `sanghiya_admin_auth_v2` (एडमिन सत्र)

### डेटाबेस का बैकअप लेने का तरीका (Backup)
1. एडमिन पैनल खोलें (`#admin`) और पासकोड `narmada2026` से लॉगिन करें।
2. **"डेटा बैकअप व सुरक्षा (Backup & Safety)"** टैब पर जाएँ।
3. **"संपूर्ण बैकअप डाउनलोड करें (.JSON)"** बटन पर क्लिक करें।
4. आपके कंप्यूटर में `Sanghiya_Narmada_Database_Backup_YYYY-MM-DD.json` फाइल सुरक्षित डाउनलोड हो जाएगी।

### बैकअप रीस्टोर करने का तरीका (Restore)
1. उसी टैब में **"JSON बैकअप फाइल चुनें"** बटन दबाएँ।
2. अपनी पूर्व में सेव की गई `.json` फाइल चुनें।
3. सिस्टम डेटा को सत्यापित कर सुरक्षित रूप से मर्ज (Merge) कर देगा, जिससे कोई मौजूदा रिकॉर्ड नष्ट नहीं होगा।

## 9. एडमिन लॉगिन व अनुमतियाँ (Admin Authentication)

- **डिफ़ॉल्ट एडमिन पासकोड:** `narmada2026`
- सत्र को `sessionStorage` में सुरक्षित रखा जाता है।
- एडमिन द्वारा किए जाने वाले कार्य:
  - आवेदनों की समीक्षा और सत्यापन स्थिति बदलना।
  - आंतरिक प्रशासनिक नोट्स लिखना।
  - एक्सेल/CSV में सदस्यों की अधिकृत सूची डाउनलोड करना।
  - नए जिले, तहसील और गाँव जोड़ना।
  - संपूर्ण JSON बैकअप लेना और रीस्टोर करना।

## 10. भविष्य में सुरक्षित बदलाव की नियमावली (Future Change Protocol)

जब भी AI या डेवलपर से इस वेबसाइट में कोई नया फीचर जोड़ने या बदलाव करने को कहा जाए, तो इस **10-चरणीय प्रोटोकॉल (10-Step Protocol)** का पालन करें:

1. **अनुरोध का विश्लेषण:** उपयोगकर्ता की आवश्यकता को स्पष्ट समझें।
2. **फाइलों की पहचान:** केवल संबंधित मॉड्यूल की फाइलें खोजें (पूरे प्रोजेक्ट को दोबारा न बनाएँ)।
3. **प्रभाव का आकलन:** जाँचें कि बदलाव से वॉलंटियर डेटा, सर्टिफिकेट या लोगो प्रभावित तो नहीं होगा।
4. **मॉड्यूलर बदलाव:** आवश्यकतानुसार साझा UI कंपोनेंट (`src/components/ui/`) का उपयोग करें।
5. **डेटा व सुरक्षा संरक्षण:** मौजूदा रिकॉर्ड्स, लोकल स्टोरेज कीज और सत्यापन लॉजिक को सुरक्षित रखें।
6. **कंपाइलेशन व लिंटिंग जाँच:** `compile_applet` व `lint_applet` चलाकर सुनिश्चित करें कि कोई सिंटैक्स त्रुटि नहीं है।
7. **मोबाइल व डेस्कटॉप रिस्पॉन्सिवनेस:** सभी आकारों पर लेआउट की पुष्टि करें।
8. **त्रुटि निवारण:** किसी भी विफलता की स्थिति में तुरंत कोड सुधारें।
9. **सरल हिंदी में रिपोर्ट:** उपयोगकर्ता को स्पष्ट बताएँ कि कौन-कौन सी फाइलों में क्या बदलाव हुआ।
10. **समीक्षा व निर्देश:** यदि कोई अतिरिक्त कदम जरूरी हो तो उसका स्पष्ट निर्देश दें।

## 11. महत्वपूर्ण सावधानियाँ (Important Project Rules)

1. **शून्य अतिरिक्त लागत:** किसी भी भुगतान वाली सेवा (Firebase, AWS, Paid APIs) को बिना स्पष्ट अनुमति के सक्रिय न करें।
2. **प्रमाणपत्र डाउनलोड नियम:** प्रमाणपत्र केवल वेबसाइट से ही सीधे PDF डाउनलोड होगा; इसे ईमेल पर भेजने का कोई विकल्प नहीं जोड़ना है।
3. **डेटा प्राइवेसी:** सार्वजनिक QR सत्यापन पेज पर किसी भी स्वयंसेवक का फोन नंबर, ईमेल या निजी घर का पता कभी प्रदर्शित नहीं करना है।
4. **असली लोगो:** हमेशा फाउंडेशन के असली गोल लोगो का उपयोग करना है।
